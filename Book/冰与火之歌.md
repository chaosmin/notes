# 冰与火之歌 — 世界观、时间线与人物关系总结

> 涵盖正传五卷 + 前传《血与火》(Fire & Blood)、《七王国的骑士》(Dunk & Egg) 系列。基于马丁出版的书籍内容，不含 HBO 剧集改编部分。

---

## 一、世界观概要

### 维斯特洛大陆（Westeros）

七大王国由铁王座统一统治，首都为君临（King's Landing）。

| 王国 | 统治家族 | 首府 | 特征 |
|------|---------|------|------|
| 北境 | 史塔克（Stark） | 临冬城 | 寒冷广袤，信仰旧神 |
| 河间地 | 徒利（Tully） | 奔流城 | 河流纵横，战略要冲 |
| 谷地 | 艾林（Arryn） | 鹰巢城 | 山地易守难攻 |
| 西境 | 兰尼斯特（Lannister） | 凯岩城 | 金矿富庶 |
| 风暴地 | 拜拉席恩（Baratheon） | 风息堡 | 多风暴 |
| 河湾地 | 提利尔（Tyrell） | 高庭 | 农业富饶 |
| 多恩 | 马泰尔（Martell） | 阳戟城 | 炎热沙漠，男女平等继承 |

此外还有铁群岛（葛雷乔伊 Greyjoy 家族）和龙石岛（坦格利安 Targaryen 旧据点）。

### 绝境长城（The Wall）

北境之北的巨大冰墙，由守夜人军团（Night's Watch）驻守，防御长城外的野人（自由民）和传说中的异鬼（Others/White Walkers）。

### 厄索斯大陆（Essos）

狭海对岸的东方大陆，拥有自由城邦（Free Cities）、多斯拉克海（Dothraki Sea）、奴隶湾（Slaver's Bay）等地。丹妮莉丝·坦格利安的大部分冒险发生于此。

### 关键历史背景

- **黎明纪元**：先民（First Men）自多恩臂迁入维斯特洛，与森林之子（Children of the Forest）爆发战争，最终达成协议，先民信仰旧神
- **英雄纪元**：筑城者布兰登建造长城与临冬城；异鬼第一次入侵，被**黎明之战**击退，传说中"最后的英雄"与亚梭尔·亚亥（Azor Ahai）用光明使者（Lightbringer）击败异鬼
- **安达尔人入侵**：安达尔人自厄索斯渡海，带来七神信仰和铁器，征服南方六国（唯独北境抵抗成功）
- **洛伊拿人迁徙**：多恩接受洛伊拿人，形成独特文化
- **坦格利安征服**：伊耿一世（Aegon the Conqueror）率三条龙统一六国（多恩除外，后以联姻并入），开创坦格利安王朝

### ⚔️ 血龙狂舞（Dance of the Dragons），129-131 AC

坦格利安家族内战，王朝由盛转衰的转折点。黑党（雷妮拉）vs 绿党（伊耿二世），龙与龙的血腥战争。

#### 家族裂痕

```
韦赛里斯一世
├── 第一任妻子 艾玛·艾林 (死于难产)
│    │
│    └── 雷妮拉·坦格利安 (唯一存活的婚生子)
│           │
│           ├──── 第一任丈夫 兰尼诺·瓦列利安
│           │    ├── 杰卡里斯·瓦列利安 (Jace)
│           │    ├── 路斯里斯·瓦列利安 (Luke)
│           │    └── 乔佛里·瓦列利安 (Joff)
│           │    ⚠️ 三个孩子生父实为哈尔温·断骨 (Harwin Strong)
│           │
│           └──── 第二任丈夫 戴蒙·坦格利安 (叔叔)
│                ├── 伊耿·坦格利安 (小伊耿，后伊耿三世)
│                ├── 韦赛里斯·坦格利安 (后韦赛里斯二世)
│                └── 死产畸形女婴 (维桑尼亚)
│
└── 第二任妻子 阿莉森·海塔尔 (绿党之母)
     ├── 伊耿·坦格利安 (伊耿二世，绿党王位主张者)
     ├── 海伦娜·坦格利安 (伊耿二世之妻/妹妹)
     ├── 伊蒙德·坦格利安 (独眼)
     └── 戴伦·坦格利安 (勇敢的戴伦)
```

**分裂根源**：韦赛里斯一世指定女儿雷妮拉为继承人，打破男性优先惯例。韦赛里斯死后，绿党（御前会议+海塔尔势力）抢先拥立伊耿二世。雷妮拉在龙石岛得知消息后怒而流产畸形女婴，誓要夺回王位。

## 五、核心预言与谜题

### 亚梭尔·亚亥 / 约定之王子

光之王预言转世英雄将重生，对抗黑暗（异鬼）。关键元素：
- 在烟与盐之地重生（龙石岛？烟与盐）
- 唤醒石中龙
- 拔出光明使者（Lightbringer）——需用生命为祭（三次铸剑，最后要以挚爱之血淬火）

候选人：史坦尼斯、丹妮莉丝、琼恩·雪诺（最广泛接受）

### 丹妮莉丝在不朽之殿的预言

- **三次背叛**：一次为血，一次为财，一次为爱
- **三次火焰**：一为生，一为死，一为爱
- **三次坐骑**：一为床笫，一为恐惧，一为爱
- **龙有三个头**：暗示需要三个坦格利安（龙骑士）——丹妮莉丝 + 琼恩 + ？

### 瑟曦的蛤蟆巫姬预言

- 不会嫁给王子，会嫁给国王
- 会有三个孩子（金发裹尸布——皆死于她之前）
- 会被更年轻的更美丽的女子推翻（玛格丽？丹妮莉丝？珊莎？）

### R+L=J

冰与火之歌最核心的谜题：雷加·坦格利安（Rhaegar）+ 莱安娜·史塔克（Lyanna）= 琼恩·雪诺（Jon Snow）。剧集已确认，书籍中大量线索指向同一结论：
- 奈德的荣誉感不容许他有一个私生子
- 极乐塔的"答应我，奈德"（Promise me, Ned）
- 丹妮莉丝在不朽之殿看到的幻象：蓝色玫瑰生长在冰墙之上
- 琼恩的身世意味着他是冰（史塔克）+ 火（坦格利安）的结合体

### 小格里芬是否为假的伊耿（fAegon）？

瓦里斯声称在君临沦陷时掉包救下了雷加与伊莉亚之子伊耿。但：
- 伊利里欧的动机存疑
- "黑火后裔"理论：小格里芬可能来自黑火母系血脉（伊利里欧的亡妻西拉？）
- 预言中"布龙（mummer's dragon）"的暗示

### 异鬼的起源与目的

正传中异鬼已回归。起源由剧集揭示为森林之子用龙晶创造以对抗先民——书籍尚未证实此设定但指向类似方向。关键线索：
- 长夜传说与黎明之战
- 长城魔法屏障
- 异鬼的语言（如冰晶碎裂之声）和组织——他们并非纯粹无意识的怪物
- 最后的英雄与凛冬之号角

**化名序列**：阿瑞（Arry）→ 尼梅利亚 → 运河之猫（Cat of the Canals）→ 贝丝（Beth）→ 梅赛蒂尼（Mercy）→ **无人（No One）**

| 属性 | 内容 |
|------|------|
| 出生年 | 289 AC，临冬城 |
| 冰原狼 | 尼梅利亚（Nymeria）— 被艾莉亚遣走，游荡于河间地，指挥一支庞大狼群 |
| 武器 | 针（Needle）— 琼恩赠送的细剑，始终未曾放弃，是她身份认同的象征 |
| 剑法 | 水之舞（Water Dancing）— 布拉沃斯茜里欧·弗瑞尔传授 |

**外貌**：史塔克长脸，灰眼睛，棕色短发；常被误认为男孩；据说酷似已故姑姑莱安娜·史塔克

**性格**：烈性、好奇，鄙视传统女红；维护死亡祈祷名单（每夜默念）；对弱者有本能正义感；左撇子；"狼血"性格

**第五卷末**：在布拉沃斯黑白之院接受无面者完整训练，已完成第一次刺杀任务，仍坚守内心的艾莉亚·史塔克认同

| 主要关系 | 备注 |
|---------|------|
| 琼恩 | 最亲近的兄长，给她"针"，灵魂纽带 |
| 尼梅利亚 | 魂兽，灵魂相连，仍在河间地领导狼群 |
| 桑铎·克里冈 | 被迫的保护者，复杂而矛盾的感情 |
| 贾昆·赫加尔 | 无面者，无面者训练的启蒙人 |

### 珊莎·史塔克（Sansa Stark）

**化名**：艾拉因·斯通（Alayne Stone）— 培提尔·贝里席的"私生女"

| 属性 | 内容 |
|------|------|
| 出生年 | 286 AC，临冬城 |
| 冰原狼 | 莱蒂（Lady）— 在前往君临途中被王室命令处死（代替尼梅利亚受罚） |
| 特长 | 刺绣、歌唱、弹高竖琴、礼仪、外交辞令 |

**外貌**：深蓝眼睛，红棕色长发（现已染为棕色以隐瞒身份）；酷似母亲凯特琳·徒利

**性格**：彬彬有礼，天生淑女；深信骑士精神和浪漫故事；在君临的苦难中逐渐以礼貌为铠甲，学会掩藏真实想法；在谷地接受小指头权谋熏陶，从天真少女成长为真正的政治参与者

**第五卷末**：藏身谷地眼镜蛇庄园，以"艾拉因·斯通"身份生活；小指头的计划：揭示她的真实身份，嫁给谷地继承人哈罗德·哈丁，以史塔克正统继承人名义夺回临冬城

| 主要关系 | 备注 |
|---------|------|
| 培提尔·贝里席 | 监护人，对她有异常的迷恋（她令他想起青梅竹马凯特琳） |
| 乔佛里（已死） | 曾爱慕的未婚夫，后令她深感恐惧和憎恶 |
| 桑铎·克里冈 | 复杂的保护者，她对他有内疚与难以言说的感情 |
| 提利昂 | 名义丈夫，待她善良，拒绝强迫圆房 |

### 布兰·史塔克（Bran Stark）

**全名**：布兰顿·史塔克（Brandon Stark，以死去的叔叔布兰顿命名）

| 属性 | 内容 |
|------|------|
| 出生年 | 290 AC，临冬城 |
| 冰原狼 | 夏天（Summer）— 灰色 |
| 状态 | 自卷一从临冬城高塔摔落后下半身永久瘫痪；须由霍多尔背负或坐特制马鞍 |

**外貌**：红棕色头发，深蓝色眼睛，酷似母亲凯特琳

**性格**：甜美善良，受所有人喜爱；瘫痪前痴迷攀爬，梦想成为骑士；瘫痪后逐渐沉入超自然的内在世界

**特殊能力**：
- **皮肤变换（Skinchanging/Warging）**：可进入夏天或霍多尔的意识（进入人类意识对霍多尔有严重心理副作用）
- **绿视（Greensight）**：通过神树心木根系观看过去（甚至可能当下）的影像；曾在临冬城过去的景象中看见父亲艾德
- **绿梦（Greendreams）**：预言性梦境；三眼乌鸦曾预言"你不会行走，但你将飞翔"

**第五卷末**：在长城以北神树心木洞穴，向三眼乌鸦（血鸦布林登·河文）学习绿视与时间感知力

| 主要关系 | 备注 |
|---------|------|
| 夏天 | 魂兽，灵魂相连 |
| 霍多尔 | 背夫，布兰可进入其意识（对霍多尔有副作用，是道德危险地带） |
| 梅拉·里德 | 旅途保护者，一路守护他到达三眼乌鸦处 |
| 三眼乌鸦（布林登·河文） | 最终导师，长满树根的枯骨，已与树木融为一体 |

3. 被更年轻更美丽的女王取代
4. 幼弟（Valonqar，高等瓦雷利亚语）会掐死她——她认定是提利昂，但瓦里斯死前宣告支持的是艾冈·坦格利安

### 詹姆·兰尼斯特（Jaime Lannister）

**别号**：弑君者（The Kingslayer）

**弑君真相**：疯王伊里斯在劳勃叛军逼近时命令引爆全城野火，詹姆杀死引燃者罗萨特，再杀疯王，阻止了一场灭城灾难——却从未对任何人解释原因，任由"弑君者"的污名伴随多年，直到向布蕾妮坦白。

| 属性 | 内容 |
|------|------|
| 出生年 | 266 AC，凯岩城，比瑟曦晚几秒出生 |
| 原有武器 | 用史塔克家族"冰"改造的瓦雷利亚钢剑，已命名"守誓剑"（Oathkeeper）赠给布蕾妮 |
| 右手 | 卷三被砍去，换上金色义手；仍在秘密练习左手用剑 |
| 入王卫年龄 | 15 岁（史上最年轻王卫成员），被"晨光之剑"亚瑟·戴恩亲自封骑士 |

**外貌**：卷曲金发，猫绿色眼睛，高挑英俊；年轻时与瑟曦相貌极为相似，连父亲泰温都曾分不清

**性格**：天生战士，对政治不感兴趣；坦率口无遮拦；失去右手后经历深刻内在转变，逐渐成长为更有担当的人；对弑君有复杂的内在荣誉逻辑；是真正认识他的极少数人（布蕾妮）才能见其真实自我

**第五卷末**：在河间地营地，随布蕾妮离去，目的地与布蕾妮意图均不明（引人深思的开放结局）

| 主要关系 | 备注 |
|---------|------|
| 瑟曦 | 孪生姐姐兼情人，ASOS 后彻底破裂，他烧掉了她的求救信 |
| 提利昂 | 弟弟，唯一真诚对待过他的家人，后因泰莎谎言彻底决裂 |
| 布蕾妮·塔尔斯 | 在共同旅途中建立奇特互敬，少数见过他真实自我的人 |
| 亚瑟·戴恩爵士（已死） | 终生崇拜的骑士偶像，极乐塔被奈德·史塔克杀死 |
