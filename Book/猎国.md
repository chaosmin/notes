# 《猎国》— 世界观、人物与剧情梳理

> 起点中文网 2009-11-17 首发连载，2013-03-12 完本。讲述野火原土鳖少年夏亚·雷鸣在拜占庭、奥丁、兰蒂斯三国鼎立的乱世中猎国称王的故事。本篇基于公开网络资料整理（百度百科、豆瓣书评、读者讨论等），非逐章精读，后期卷次（尤其第九卷以后）公开资料本身就比较简略、且读者对结局质量评价分歧很大，行文中已标注存疑之处。

---

## 一、世界观设定

| 阵营/概念 | 说明 |
|---|---|
| 拜占庭帝国 | 大陆南方古老帝国，首都奥斯吉利亚，皇室克伦玛家族。内部军阀割据（军阀党）与皇室长期对峙，国力日渐衰弱 |
| 奥丁帝国 | 大陆北方军事强国，统治者称"神皇"，索尔家族为皇室，精锐军团为黑旗军，尚武好战 |
| 兰蒂斯 | 大陆西方岛国，魔法立国，拥有大魔导师体系；后期与拜占庭皇室缔结不平等条约参战 |
| 野火原 | 三国势力接壤的缓冲旷野，法外之地，夏亚与艾德琳相识之地，各方势力盘踞 |
| 巴比伦（混乱之领） | 凌驾于三国世俗权力之上的古老领域，圣罗兰加洛斯家族世代镇守，是全书顶尖强者最终较量的舞台 |
| 圣罗兰加洛斯家族 | 巴比伦的守护者血脉，夏亚是该家族的"圣罗兰候选人"之一；三十年前曾出手击败意图凌驾世俗的奥丁神皇 |
| 郁金香家族 | 拜占庭旧贵族，数百年前被皇室灭门仅存一脉（即老家伙一系），血脉实源自圣罗兰一系 |
| 九大强者 / 神之境界 | 三十年前联手（实为圣罗兰加洛斯出手）击败奥丁神皇、订立"强者不与世俗争锋"之盟的顶尖强者群体；神皇后期突破"神之境界"，违约逐一击败昔日盟友，是全书后期的终极危机 |
| 四扇门 | 郁金香家族旧宅密室，据传"救赎之门"需双血启动、"堕落之门"需亲子之血启动，牵连夏亚与郁金香/圣罗兰血脉之谜（具体触发细节公开资料语焉不详，待考） |
| 大赌局 | 宰相卡维希尔"先破后立"的总体战略：①驱虎吞狼——逼军阀党反叛、勾结奥丁入侵，放弃北方令奥丁与军阀党互斗；②联兰蒂斯搅局，把局面搅得更复杂；③凭险固守帝都、整合南方，待两败俱伤后收官，扶植独裁体制 |

| 属性 | 内容 |
|---|---|

| 武器/能力 | 屠龙所得传说饰物"永恒之泪"；奥丁神皇所赠记忆水晶中藏有的"雷云大光明术"；由劈柴、切豆腐、开膛破肉等日常"斧技"苦练出的实战根基 |
| 身份/头衔 | 拜占庭帝国护国摄政王（终局）；卡维希尔"大赌局"选定的独裁者候选人 |

**外貌**：公开资料未见详细描写，原著中以"土鳖"气质著称——待原著确认。

**性格**：出身草莽，务实狡黠、贪财好色又重情重义；前期插科打诨投机取巧，随势力壮大逐渐扛起家国责任；经典台词"不想谋朝篡位的权臣不是一个合格的权臣……总有一天，帝国的金币上会印上老子的头像！"很好地概括了他亦正亦邪的权臣自觉。

**结局/现状**：终局被封为拜占庭帝国护国摄政王，迎娶艾德琳；与黛芬妮之子被立为皇位第一顺位继承人（实为夏亚亲生骨肉），但夏亚遵守对阿德里克的承诺，未直接篡夺皇位；五年后米纳斯公爵病故，夏亚完成了从野火原土鳖到帝国实际掌控者的猎国之路。

## 三、剧情梗概

### 第一卷 · 荣耀之军（野火原出山）

- **老家伙去世**，是夏亚走出野火原的直接契机
- 进入野火镇，在黑街与各方势力周旋，结识化名"可怜虫"的少女（实为拜占庭公主艾德琳）
- 以猎魔人身份起家，骗魔法师多多罗当跟班
- **屠龙壮举，获得传说饰物"永恒之泪"**
- 加入拜占庭军队，初历战争，崭露锋芒

### 第二卷 · 生命魔法（莫尔郡初战）

- 夏亚被分配至北方莫尔郡驻守
- 初次遭遇奥丁帝国黑旗军及其统帅**黑斯廷**（大陆顶尖强者），此时同门身份尚未点破
- 格林等宿将奉命辅佐夏亚
- **夏亚在与黑斯廷的交手中初次领略大陆强者的真正实力**
- 抗击奥丁战斗中表现突出，被召往帝都面见骑枪大帝康托斯

### 第三卷 · 四扇门（帝都风云）

- 抵达帝都奥斯吉利亚，卷入太子妃刺杀案，深陷皇室与军阀党的权力漩涡
- **帝国宰相卡维希尔开始暗中关注、培养夏亚为"独裁者候选人"**
- 在郁金香家族旧宅发现密室"四扇门"，牵出郁金香家族与圣罗兰血脉的秘密传承
- 卡维希尔向夏亚透露其"大赌局"计划的雏形

### 第四卷 · 神奇女巫（梅林登场）

- 传奇女巫**梅林**正式登场，作为夏亚养母出现在帝都，为其提供指引和庇护
- 夏亚继续周旋于皇室与军阀党的政治斗争中，实力和势力稳步增长

### 第五卷 · 屠蛇行（冒险历练）

- 夏亚踏上屠蛇之旅，深入险境猎杀传说魔兽**达曼德拉斯巨蛇**，帮助扎库部落
- 探险途中在远古地精创神区被巨蛇追杀，**梅林及时赶到将巨蛇化为青蛙**，众人得救
- 扎库部落大酋长之女**素灵**与女巫**了了**均对夏亚暗生情愫，扎库部落自此成为夏亚最坚实的盟友
- 各方势力对这位新兴人物的关注度持续加大

### 第六卷 · 强者之强（内战爆发，大赌局启动）

- 拜占庭帝国内战全面爆发：距帝都直辖区最近的亚美尼亚军区第一个竖起叛旗，其余军阀纷起响应
- 奥丁乘虚而入，夏亚驻守的莫尔郡首当其冲，遭遇奥丁精锐赤雪军团
- **卡维希尔为启动"大赌局"，一手安排自己"遇刺身亡"**，计划正式进入三个步骤：①驱虎吞狼——逼军阀党反、勾结奥丁入侵，放弃北方令奥丁与军阀党互斗；②联兰蒂斯搅局，把局面搅得更复杂；③凭险固守帝都、整合南方，坐待两败俱伤后收官
- 夏亚在莫尔郡孤军奋战，于丹泽尔城建立根据地，势力初具雏形

### 第七卷 · 黑斯廷（宿敌对决）

- **黑斯廷身世揭秘**：夏亚同门师兄，全家被拜占庭皇帝克伦玛一族灭门，投奔奥丁并取用历史名将"黑斯廷"之名，立志灭绝拜占庭皇室
- 老家伙生前预言**"我这一生有两个传人，其中一个会死在另外一个手里"**，要求黑斯廷承诺饶过师弟三次
- 黑旗军兵临丹泽尔城，**夏亚与黑斯廷正面交锋**——二人的对决被视为"神性秩序 vs 野性本能"的武道哲学碰撞

### 第八卷 · 泣血歌（悲壮高潮）

- **罗德里亚骑兵团在绝境中高唱战歌"罗德里亚！向前！！！"发动最后的冲锋，全军覆没**，是全书公认最悲壮的篇章
- 骑枪大帝康托斯临终托孤，**阿德里克将军身死皇宫**
- 梅林撮合夏亚婚事，**艾德琳的真实身世（奥丁-拜占庭双重血统）揭晓**
- 夏亚收编罗德里亚残部，吞并各方势力，实力急剧膨胀

### 第九～十二卷 · 猎国终章（霸业完成）

> 公开资料对这几卷的记录明显比前八卷简略，读者书评普遍认为后期"降智""流水账化"，以下按主题整理关键线索，而非严格逐卷。

**北方军政分离与财政改革**：北方军坐大为拜占庭第一豪强，但军管体制不利于整合发展；**苏菲力主军政分离**——格林专任军务、苏菲主政务，若有冲突由艾德琳仲裁；随后又推行赏罚分明、军制变革、废除农兵制改行预备役、以实物代钱财行赏等财政改革，为夏亚日后的猎国与强国打下基础。

**米纳斯自立与罗迪出走**：南方米纳斯公爵拥兵自立；其子**罗迪不认同父亲做法，率精锐骑兵出走**，以运动战周旋于帝国东部军阀之间。夏亚暗中相助（借绯红杀气助其攻城、献围点打援之策），助罗迪扭转战局。

**达克斯的帝都棋局**：达克斯策划打破帝都与米纳斯之间的势力平衡——利用米纳斯之孙戴维"具大魔导师潜质"的流言引发加西亚猜忌暗杀，再借机救出继承人李尔并收归己用，为南北整合铺路。

**帝国内战与兰蒂斯入局**：骑枪大帝康托斯病故后加西亚继位，与兰蒂斯缔结不平等条约换取参战；军阀同盟收买帝都贵族里应外合，一度攻破帝都，局势持续动荡。

**巴比伦终局——神皇突破与欧克对决**：三十年前，奥丁神皇曾意图凌驾世俗权柄，被"圣罗兰加洛斯"击败，订立"强者不与世俗争锋"之盟后隐退让位；三十年后神皇突破**神之境界**，违约逐一击败当年联手的九大强者，攻破巴比伦城；**欧克在另一空间与神皇展开终极对决**（网络流传的章节顺序大致为：【神皇VS欧克】→【一块红豆饼】→【谁挡强梁】→【帝都】→【可曾想过今日】→【终落泪】→【别院里的四扇门】→大结局）。黑斯廷据称也在此间与神皇有过交手、"明白了力量"却未能取胜，其**最终生死公开资料没有定论，说法不一，待核实**。

**大结局**：战争结束前夜，皇后黛芬妮在郁金香家族别院产下一子，帝国宣布此子为**皇位第一顺位继承人**——这个孩子实为夏亚的亲生骨肉。夏亚被封为**拜占庭帝国护国摄政王**，迎娶艾德琳；众人心知肚明皇位血脉实为夏亚一系，但夏亚遵守对阿德里克的承诺，没有直接篡夺皇位；拜占庭帝国在夏亚、米纳斯公爵、罗迪和鲁尔等人的主持下全面恢复。五年后，米纳斯公爵病故。夏亚完成了从野火原土鳖到帝国实际掌控者的猎国之路——正如他当年的豪言："总有一天，帝国的金币上会印上老子的头像！"

> 网络上流传"跳舞太监（弃更）猎国"的说法，但多个售书/阅读平台的章节记录（不同平台统计口径不一，从 585 章到 602 章、612 章不等）都显示全书确有明确的"大结局"收尾章节，说明小说本身是完结的，"太监"更像是早期未完结阶段流传下来的旧传闻；读者的争议主要集中在结局质量本身——后期节奏仓促、多位有故事有魅力的配角（维亚、达克斯、素灵等）结局未详细展开，部分书评直呼"烂尾"。
