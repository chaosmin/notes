description: Book（书籍）笔记的 Agent 指令
---

AI 写书籍笔记参考。目标：人物立体、剧情脉络清楚，非流水账。

## 文档模板章节

按顺序，`*` 号章节为可选（视书籍类型取舍，非每本都要）：

### 1. Frontmatter

沿用现有字段，按需增删：

```yaml
---
title: 书名
type: book
status: completed | ongoing
genre:
  - 类型标签
author: 作者
name_en: 英文原名        # * 引进版/外国作品
studio: 出版社
platform: 起点中文网 / 番茄小说   # * 网络小说注明连载平台
published: 年份
volumes: 卷数
word_count: 字数
douban: 评分
rating_platform: 站内评分   # * 番茄/起点等站内分与豆瓣分差异大时列出
adaptations:              # * 有改编才写
  - 影视/游戏/动画
related:                  # * 系列作品互相 [[wikilink]]
  - "[[另一本书]]"
cover: 封面或代表性图片 URL   # *
---
```

### 2. 世界观设定 *

设定复杂（异世界、多方势力、专有体系）的书才写。表格列出阵营/地域/核心概念，一行一个，不展开叙述。

### 3. 主要人物

两层结构，不要只写一张笼统表就收尾：

**3a. 总览表** — 全部有名有姓角色一行一个：`角色 | 身份 | 一句话核心`。

**3b. 核心人物详细档案** — 只展开真正主角/关键角色（3~8 人，太多则说明"仅列核心，其余见总览表"）。每人一个二级/三级标题，含：

- 属性表：出生、武器/能力/坐骑等书内设定项（按书籍类型取舍字段，不套死格式）
- 外貌（一两句）
- 性格（结合书中具体情节说明，不写空洞形容词）
- 结局/现状（写到原著/资料截止进度为止）
- 关系表：`主要关系 | 备注`
- 配图 *：见下方"配图"小节

参考基准：`冰与火之歌.md` 第七节"核心人物档案"的写法。禁止参考基准：`猎国.md`、`十日终焉.md` 目前的单表流水账式写法——这是本次要避免重蹈的问题。

### 4. 人物关系图 *

角色关系错综复杂（多代家族、多阵营对立）时加，用 ascii tree 或 mermaid。简单书不用硬凑。

### 5. 剧情梗概

按卷/部分组织，每卷：

- 标题 + 一句话定位（如"死灵深渊（草庙村 → 滴血洞）"）
- 关键事件分小标题展开，不是无标题大段文字墙
- 重大转折点/牺牲/揭秘用**加粗**标出
- 关键场景配图 *：见下方"配图"小节

### 6. 关键设定/物品/术语表 *

书里反复出现且影响剧情走向的专有名词（如"天书五卷""道""回响"），一张表说明含义与获取时机/触发条件。

### 7. 名场面/名台词 *

加分项，非必须。原文引用 + 一句上下文。

### 8. 说明

固定 disclaimer，注明整理基于的公开资料来源（豆瓣/百科/书评/Wiki/读者讨论），非逐章精读；如与原著有出入建议以原著为准。

## fetch 书内容标准执行步骤

1. **基本信息**：WebSearch 豆瓣读书条目，拿评分、作者、出版社、卷数、字数。网络小说另查连载平台（起点/番茄）和站内评分。

2. **世界观/设定**：WebSearch 百度百科词条 + 知乎书评 + 贴吧精华帖；有英文条目的作品查对应 Fandom Wiki（如冰与火之歌查 `awoiaf.westeros.org`）。

3. **人物列表**：角色百科页 / 小说人物分析文章 / Wiki character page。先建总览表，再挑核心角色深挖第 3b 节所需字段。

4. **逐卷剧情**：书评网站的详细梗概帖、读者整理帖、Wiki plot summary 至少交叉两个来源核对。人物结局/关键转折点如两个来源说法不一致，笔记中标注"（说法不一，待核实）"，不要凭猜测二选一。

5. **配图**（有条件才加，不硬凑）：
   - 西方奇幻/有英文 Wiki 的作品优先：Fandom/专题 Wiki 角色页通常有高清角色画像，直接用图片 URL 外链嵌入 `![角色名](url)`，不下载到本地
   - 页面是 JS 渲染、WebFetch 抓不到图片地址时，用 Playwright MCP（`browser_navigate` 打开角色页 + 读取 img 元素的 src）取真实图片 URL
   - 中文网络小说通常没有角色画像 Wiki：可用官方封面图；同人图/剧照要能确认来源才用，标注来源；找不到可靠图源就不加，不编造链接
   - 图片放在对应人物档案小节或关键场景段落下方，不要堆在开头

6. **写入笔记**：按上方模板章节顺序落笔，字段/章节按书籍类型取舍（* 号章节视情况省略）。

7. **收尾**：按第 8 节格式写 disclaimer，注明信息来源类型和整理方式。
