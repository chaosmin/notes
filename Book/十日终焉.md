# 《十日终焉》

> 时空循环悬疑脑洞群像文。主角齐夏与形形色色的参与者被卷入"终焉之地"，以十日（实为十二日）为周期反复经历死亡游戏，唯有觉醒"回响"异能者能带着记忆轮回。以下内容基于公开网络资料整理，非逐章精读，结局等关键情节已交叉多个信源核实，仍有分歧处已标注。

---

## 世界观设定

| 概念 | 说明 |
|---|---|
| **终焉之地** | 一座（实为多座并存的"沉沦城市"之一，如齐夏所在城 + 郑英雄所在城）破败诡异的封闭空间。参与者因地震等意外"死亡"后被卷入，外界时间静止，内部生死轮回 |
| **桃源 / 女娲游戏** | 终焉之地的更古老起源：约 70～84 年前，天龙、青龙的"主人"为造新神，召集双龙与许流年等带 5 万阴魂进入"桃源"执行"女娲游戏"——桃源可让极端情绪下的人获得"神力"。后天龙欲自己成神，废弃女娲游戏原本的裁判体系，改由自己选拔的生肖接管 |
| **十日轮回** | 表面每十日一个生死周期，死后于第十一天失忆复活；实际内核是**十二日一轮**——天龙为避免新旧参与者接触，每 12 天"离析"一次参与者，其中 2 天用于"入梦"，参与者感知到的才是"十日" |
| **生肖** | 佩戴十二生肖面具的"管理者"，分人级 / 地级 / 天级，通过引导参与者死亡获得晋升。人级主持低难度游戏赚取"道"；地级以"赌命"为目的清洗参与者、制造"原住民"；天级统领全局，发动全城范围强制游戏 |
| **四大神兽** | 青龙（掌管规则，与天龙同为终焉之地最高掌控者）/ 白虎（调停生肖间残杀，真实身份为文巧云）/ 朱雀（审判违规生肖）/ 玄武（裁决杀人夺道与生肖赌命） |
| **道** | 金色小球，游戏筹码。传言集齐 3600 颗可"逃离"——后被揭露为骗局：集齐将触发天龙、青龙"洗牌"，抹除所有人记忆并大规模屠杀，一切归零重来 |
| **回响** | 参与者在濒死之际因内心执念具象化而觉醒的超自然能力，全书设定超过 50 种。名字取自"念念不忘，必有回响" |
| **回响者** | 能在轮回清洗中保留部分记忆的人，信念强度决定其回响的形态与强度 |
| **原住民（颠人）** | 被生肖反复赌命清洗到失去理智的参与者，终焉之地的底层"NPC" |
| **三大江湖势力** | 天堂口（楚天秋）、极道（燕知春）、猫（钱五）——各自以不同方式在终焉之地的规则夹缝中求生或反抗 |

### 核心人物详细档案

#### 齐夏

| 属性 | 内容 |
|---|---|
| 表面身份 | 自称诈骗犯，涉案约 200 万元 |
| 真实履历（据部分解读，说法不一，待核实） | 疑似 70 余年前带头挑战天龙失败、觉醒"生生不息"的反抗者；10 年前曾集结近万参与者再次集齐 3600 颗道挑战天龙，落败后所有人被清洗，仅钱五等极少数保留记忆；此后 7 年从"人羊"一路做到"地羊"，即将晋升"天羊"时因遭遇天龙而失忆，重新沦为普通参与者 |
| 回响 | 早期为"灵闻"（感知类），后期真正的核心回响为**生生不息**——信念可具象化为现实存在（曾创造出"余念安"） |
| 关键道具 | 无固定武器，胜负手始终是心理博弈与逻辑推演 |

**外貌**：网络资料着墨有限，仅知常年面无表情、眼神冷淡，不见明显情绪起伏。

**性格**：阴沉不喜言笑，智商与逻辑思维远超常人，队友当场惨死也能瞬间调整心态、冷静指挥下一步——团队心理咨询师林檎因此断言"齐夏应该有很严重的心理问题"。他对绝大多数事情漠不关心，唯独涉及亡妻余念安时会突然变得脆弱、敏感、易怒，这是他人格中唯一暴露的裂缝。

**结局**：齐夏最终选择正面对抗天龙与青龙（双龙），代价是几乎全部参与者阵亡；凭借最后的计划，他让乔家劲、陈俊南、章晨泽、楚天秋等同伴获得"重生"、真正脱离终焉之地的轮回。但他自己因此获得"神格"，永远留在终焉之地成为维持秩序的孤独守护者——救下了所有人，却唯独没能拯救自己。这一"孤独英雄式"结局在读者中评价两极，也有人认为部分伏笔（如魏杨的最终作用）未被充分回收。

> 以下按现有实体书 10 册（囚笼 / 迷城 / 不息 / 乐园 / 万相 / 白羊 / 极道 / 因果 / 入梦 / 钟鸣）的情节逻辑分卷组织。册与册之间的具体章节边界网络资料记载不完全一致，此处按情节脉络排布，仅供参考，精确边界建议以原著实体书为准。

### 第一卷 · 囚笼（初入终焉）

- **说谎者游戏**：齐夏在密闭房间与其他九人被迫参与"说谎者"游戏，全员抽到"说谎者"身份牌。**齐夏识破人羊藏在规则中的谎言，反杀通关，人羊开枪自尽**——这是全书第一场死亡游戏
- **组队与初战**：随后经历仓库寻道、黑熊狩猎等连环游戏，组建初始团队——乔家劲、甜甜、林檎、李尚武、韩一墨；"地牛"游戏中乔家劲徒手对抗黑熊，两队各获 19 颗道
- **团队内耗**：极道成员潇潇伪装接近团队，**毒杀乔家劲与甜甜**，逼齐夏放弃集道；齐夏在人猪黑白棋中以概率学破解赌命局；地狗谍战游戏中破解凯撒密码（明文"极道万岁"），江若雪暴露卧底身份
- **尾声**：齐夏重生回到地震前一天，发现妻子余念安已被终焉之地抹去了一切痕迹

### 第二卷 · 迷城（天堂口博弈）

- **加入天堂口**：齐夏保留记忆重启轮回，从人羊尸体上搜出《生肖飞升对赌合同》，得知生肖晋升的方式是引导参与者死亡；加入天堂口组织，首领楚天秋长期拒绝露面
- **跷跷板惨案**：楚天秋设局"人龙跷跷板"游戏——**甜甜割颈牺牲，李尚武断臂身亡**，是全书最残酷的团队内耗游戏之一
- **反制与揭露**：人猴"箱中道"游戏中齐夏以骗术反制作弊魔术师；随后揭露楚天秋惯用手法——利用回响者假扮自己以隐藏行踪
- **地虎对决**：齐夏与赵医生组队破解地鸡兵器牌游戏；面对地虎"狭路相逢"时，**乔家劲触发"破万法"回响、张山触发"天行健"**，联手击败极道小队

### 第三卷 · 不息（真相浮现）

- **濒死觉醒**：齐夏被许流年嫁祸，遭神兽玄武虐杀，濒死之际**触发"生生不息"回响**——强烈的信念可将想象之物具象化为现实；重生后与余念安的"替身"重逢，证实她正是回响创造的产物
- **楚天秋的野心**：揭穿楚天秋收集死者尸体提取回响、妄图"成神"掌控终焉之地的真相
- **抉择**：齐夏将自己辛苦集得的 2900 颗道托付地虎保管，决定不再追逐"集齐 3600 颗道即可逃离"的旧路

### 第四卷 · 乐园（旧日队友与"道"的骗局）

- **陈俊南回归**：揭示十年前齐夏曾带领七名回响者险些集齐 3600 颗道；**"道"的真相被揭穿——集齐 3600 颗会触发天龙与青龙的"洗牌"，抹除所有人记忆并大规模屠杀参与者，一切从头开始**，上一次齐夏的队伍正是这样被清洗的
- **地蛇博弈**：陈俊南与云瑶通过天花板潜行配合"替罪"回响破解地蛇"少数与多数"游戏，逆转局势；苏闪、秦丁冬在灾厄年游戏中破解四季灾厄规则，全员存活
- **多城真相**：郑英雄来自另一座"沉沦城市"，揭示终焉之地并非唯一，存在多区域并存
- **白虎身份**：**白虎文巧云的真实身份被揭露——她是三十年前参与者的首领，也是楚天秋的昔日恋人**

### 第五卷 · 万相（八大地级生肖）

- 天马时刻的全城强制逃亡中，齐夏被许流年所救；**青龙降临**，测试齐夏并给出八个地级生肖所在位置的地图
- 八个地级生肖与齐夏渊源极深——很可能都是他过去认识的人；齐夏面临抉择：猎杀他们晋升为天级生肖，还是选择另一条路

### 第六卷 · 白羊（身份之谜）

- 齐夏深入调查地级生肖，越接近真相越感到不安；**"天羊"的身份逐渐浮出水面——齐夏可能就是那位失去记忆、被打回参与者身份的天羊本人**
- 他曾是天级生肖之一，飞升失败后记忆清零、重新进入终焉之地；围绕"天羊"秘密，各方势力重新洗牌

### 第七卷 · 极道（全面冲突）

- 极道组织全面登场——以摧毁一切规则为目标的最暴力反抗组织；极道、天堂口、生肖三方鼎立的局势彻底白热化，齐夏在夹缝中寻找自己的道路

### 第八卷 · 因果（轮回真相）

- 揭示终焉之地的因果链条：参与者为何会来到此地；**白神兽揭露致命真相——所谓"逃出去"从头到尾都是谎言，参与者所在的现实世界早已消失**，终焉之地既是牢笼也是最后的避难所
- 每个人的"回响"都源于内心最深处的执念与创伤

### 第九卷 · 入梦（天龙之邀）

- **天龙拉齐夏入梦**，邀请他共同创造"新世界"——天龙代表绝对秩序，齐夏代表人心与自由，齐夏拒绝合作；**天龙与青龙就此决裂**，青龙认为天龙的计划已然失败
- 生肖开始选边站队；齐夏与楚天秋各率队伍挑战地龙"仓颉棋"游戏，登上生肖列车，为最终决战做准备

### 第十卷 · 钟鸣（终焉之战与结局）

- 仓颉棋游戏中青龙犯规，玄武与青龙开战；极道众人摧毁象征终焉之地秩序的**巨钟与显示屏**，全面战争爆发；猫队击杀玄武、朱雀；众人分八支小队进入生肖列车；原住民逐渐恢复理智，终焉之地的底层规则开始崩坏
- **最终决战与真相**：齐夏正面迎战双龙（天龙 + 青龙）。此役代价惨重——几乎所有参与者阵亡，**只有齐夏与白虎（一说）存活**（此处不同信源细节略有出入，待核实）
- **结局**：凭借"生生不息"与最后的计划，齐夏为死去的同伴安排了"重生"——乔家劲、陈俊南得以脱离轮回，回到北京胡同重逢；章晨泽摆脱原生家庭阴影，与所爱之人成婚；楚天秋脑肿瘤消失，获得新生；钱五与猫团聚；舒画与"小玄武"重生；余念安"重生"成为齐夏灵魂中的唯一伴侣。**齐夏本人却因此获得"神格"，永远留在终焉之地，成为维持秩序的孤独守护者，无法真正离开或与任何人团聚**——双龙的统治瓦解，"逃离"骗局与十二生肖体系随之终结，但齐夏用尽千年万年乃至永恒的孤独，换来了所有人的美好结局，唯独没有自己的
- 结局争议：反派魏杨此前被塑造得极具神秘感与威胁性（"读心超越天蛇，格局大于双龙"），但最终未获得与铺垫相称的剧情交代，是读者讨论中较大的遗憾点之一

### 书中详写的经典游戏

**人羊 · 说谎者** — 全书第一个游戏。9 人参加，全员抽到"说谎者"身份牌。规则：所有人讲述来到终焉之地前最后发生的事，其中有且仅有一人说谎，众人投票选出说谎者。齐夏识破人羊在规则中隐藏的谎言，反杀通关，人羊开枪自尽。

**人狗 · 雨后春笋** — 10 人以内，转动桌子 100 次获取盾牌，天花板随机掉落鱼叉。团队协作分配盾牌数，存活即为胜利。

**人猴 · 箱中道** — 魔术师人羊在箱子中暗藏机关作弊。齐夏以骗术反制，识破其手法。

**人龙 · 跷跷板** — 龙类代表"天平与人性"。4v4，双方站于跷跷板两端，通过抉择制造失衡。楚天秋设局，甜甜割颈牺牲，李尚武断臂身亡，是全书最残酷的团队内耗游戏。

**人猪 · 摸棋猜色** — 概率类游戏，齐夏以概率论与逻辑闭环破解赌命局。

**地蛇 · 少数与多数** — 12 人逻辑博弈。每轮投票选少数派，多数派被制裁。蛇类核心成分为"狡诈"。

**地鸡 · 兵器牌** — 争斗类卡牌对战。齐夏与赵医生组队，以心理战术和牌序规划逆转获胜。

**地虎 · 狭路相逢** — 3v3 独木桥对抗。虎类融合体力、争斗与团队配合。乔家劲在生死之际触发"破万法"回响，无效化地虎能力。

**地狗 · 送信人** — 4v4 团队游戏，卷入极道与生肖之间的谍战。破解凯撒密码（明文"极道万岁"），江若雪暴露身份。

**地狗 · 灾厄年** — 新地狗主持，4+1 人。模拟四季灾厄的生存挑战，苏闪、秦丁冬破解规则全员存活。

**地龙 · 仓颉棋** — 7v7，齐夏队 vs 楚天秋队。全书高潮对战之一，龙类地级必为一阴一阳组合（地阳龙 + 地阴龙），仓颉棋为地阴龙主持。

**天马时刻** — 天级生肖以整座城为范围强制发动。马对应午时（11:00-13:00），全城参与者被强制卷入生命竞速，无论是否正参与其他游戏，持续一个时辰。

**天蛇时刻** — 天蛇向全城所有参与者提问，必须作答。在蛇对应时辰发动。
