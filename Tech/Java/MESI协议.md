# MESI协议

MESI（Modified, Exclusive, Shared, Invalid）协议是一种广泛使用的缓存一致性协议，主要用于维护 CPU 缓存与主内存之间的数据一致性。在多核处理器系统中，各个核心的缓存可能存在数据不一致的问题，MESI 协议定义了四种状态来标记缓存行的状态。

## Modified 状态

表示当前缓存行的数据是修改过的（即与主内存中的数据不一致），并且只在当前 CPU 的缓存中是修改过的。

## Exclusive 状态

表示当前缓存行的数据是有效的，且在其他CPU的缓存中没有该行数据。同时，当前缓存行数据与内存中的数据相同。

## Shared 状态

表示多个CPU的缓存中均缓存有这行数据，并且缓存中的数据与内存中的数据一致。

## Invalid 状态

表示当前缓存行中的数据无效。
