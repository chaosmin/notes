# Java：集合

## List 有序集合

### Vector
**Vector** 是 Java 早期提供的**线程安全**的动态数组。其内部使用对象数组来保存数据，可以根据需要自动扩容，当数组已满时，会创建容量提高 *100%* 的新数组，并拷贝原有数组数据。

### ArrayList
**ArrayList** 是应用更加广泛的动态数组实现，它本身不是线程安全的，所以性能好很多。它也可以根据需要调整容量，每次调整会增加 *50%* 的新容量。

### LinkedList
**LinkedList** 是**双向链表**，不需要调整容量，也不是线程安全的。

#### 性能对比
- Vector 和 ArrayList 作为动态数据，其内部元素以数组形式顺序存储，非常适合随机访问的场合。但除了尾部插入和删除元素，其他操作往往性能会比较差，比如需要在中间位置插入元素时，需要移动后续所有元素。
- LinkedList 进行节点插入、删除就高效得多，但是随机访问性能则要比动态数组差。

## Set 不允许重复元素的集合

### TreeSet
**TreeSet** 支持自然顺序访问，但是添加、删除、包含等操作要相对低效 $O(log(n))$

### HashSet
**HashSet** 利用哈希算法实现，理想情况下如果哈希散列正常，可以提供 $O(1)$ 的添加、删除、包含等操作，但是不保证有序。

### LinkedHashSet
**LinkedHashSet** 内部构建了记录插入顺序的双向链表，可提供按照插入顺序遍历的能力。可以提供 $O(1)$ 的添加、删除、包含等操作，但由于要维护链表的开销，性能会略低于 HashSet。

#### 遍历性能对比
在遍历元素时，HashSet 性能受自身容量影响，所以初始化时，不要将其背后的 HashMap 容量设置过大。而对于 LinkedHashSet，由于其内部链表提供的方便，遍历性能只和元素多少有关系。

## Queue/Deque 标准队列

- LIFO（后进先出）

## 排序

### 原始数据类型排序
对于原始数据类型，目前只用的是 **双轴快速排序 Dual-Pivot QuickSort**，这是一种改进的快排算法。

### 对象数据类型排序
对于对象数据类型，目前使用的是 **TimSort**，思想上也是一种归并和二分插入排序结合的优化排序算法。

### 并行排序
JDK8 引入了 **并行排序算法**，充分利用现代多核处理器的计算能力，底层实现基于 fork-join 框架。在数据量小的时候，提升并不明显，甚至还表现差一点；但是当数据集增长到数万或百万以上时，提高就非常大了。
