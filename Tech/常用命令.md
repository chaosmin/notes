# 常用命令

## Maven

### 清除所有 .lastUpdated

```bash
find /h/develop/.m2/repository -name "*.lastUpdated" -delete
```

### 强制刷新本地仓库

```bash
mvn dependency:purge-local-repository
```

## Git

### 提交历史查询

### 修改 git 邮箱信息

```bash
git config user.email "you@company.com"
```

### 修改上一次提交的用户信息

```bash
git commit --amend --author="Your Name <you@company.com>" --no-edit
```
