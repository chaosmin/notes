### 单例模式 Singleton

```java
public class Singleton {
  private static volatile Singleton singleton = null;
  private Singleton() {}

  public static Singleton getSingleton() {
    if (singleton == null) {
      synchronized (Singleton.class) {
        if (singleton == null) {
          singleton = new Singleton();
        }
      }
    }
    return singleton;
  }
}
```
