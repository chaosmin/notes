# 算法：归并排序

## 题目

## 思路

**原理**：分治法。数据一分为二，分别排序后合并两个有序数组。

**特点**：稳定，适合大数据量。

## 代码

```java
public static void mergeSort(int[] arr, int left, int right) {
    if (left < right) {
        int mid = (left + right) / 2;
        mergeSort(arr, left, mid);     // 左半部分排序
        mergeSort(arr, mid + 1, right); // 右半部分排序
        merge(arr, left, mid, right);   // 合并有序数组
    }
}

private static void merge(int[] arr, int left, int mid, int right) {
    int[] temp = new int[right - left + 1];
    int i = left, j = mid + 1, k = 0;
    while (i <= mid && j <= right) {
        temp[k++] = (arr[i] <= arr[j]) ? arr[i++] : arr[j++]; // 按序合并
    }
    while (i <= mid) temp[k++] = arr[i++];   // 处理剩余元素
    while (j <= right) temp[k++] = arr[j++];
    System.arraycopy(temp, 0, arr, left, temp.length); // 回写
}
```

## 复杂度分析

- 时间复杂度 $O(nlogn)$
- 空间复杂度 $O(n)$
