# 算法：接雨水

#栈 #数组 #双指针 #动态规划

### 题目

> 给定 `n` 个非负整数表示每个宽度为 `1` 的柱子的高度图，计算按此排列的柱子，下雨之后能接多少雨水。

**示例 1：**

![](https://assets.leetcode-cn.com/aliyun-lc-upload/uploads/2018/10/22/rainwatertrap.png)

```
输入：height = [0,1,0,2,1,0,1,3,2,1,2,1]
输出：6
解释：上面是由数组 [0,1,0,2,1,0,1,3,2,1,2,1] 表示的高度图，在这种情况下，可以接 6 个单位的雨水（蓝色部分表示雨水）。
```

**示例 2：**

```
输入：height = [4,2,0,3,2,5]
输出：9
```

**提示：**

`n == height.length`
`1 <= n <= 2 * 104`
`0 <= height[i] <= 105`

### 思路

根据木桶原理，第 `i` 格能接多少水是由 `i` 左右两边的柱子中更矮的那个的高度决定的。其蓄水量应为 $min(left[i], right[i]) - height[i]$，如果结果为负数证明第 `i` 格无法蓄水。

所以我们先生成 `i` 左右两次分别最高的柱子的关系 `left[]` 及 `right[]`，之后遍历 `i = 1` 至 `i = n - 2` 的所有情况（左右两侧由于缺少柱子无法蓄水），根据上述公式求得最终的蓄水量。

### 代码

```java
class Solution {
    public int trap(int[] height) {
        int n = height.length;
        int[] left = new int[n];
        int[] right = new int[n];

        int sum = 0;

        for (int i = 1; i < n - 1; i++) {
            left[i] = Math.max(height[i - 1], left[i - 1]);
        }
        for (int i = n - 2; i > 0; i--) {
            right[i] = Math.max(height[i + 1], right[i + 1]);
        }

        for (int i = 1; i < n - 1; i++) {
            int min = Math.min(left[i], right[i]);
            if (min > height[i]) {
                sum += min - height[i];
            }
        }

        return sum;
    }
}
```

### 复杂度分析

- 时间复杂度：$O(n)$
- 空间复杂度：$O(1)$
