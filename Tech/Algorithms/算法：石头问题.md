# 算法：石头问题

#动态规划

### 题目

> 有一堆石头，每块石头的重量都是正整数。每次从中选出任意两块石头，然后将它们一起粉碎。假设石头的重量分别为 $x$ 和 $y$，且 $x \le y$。那么粉碎的可能结果如下：
> 1. 如果 $x$ 和 $y$ 相等，那么两块石头都会被完全粉碎；
> 2. 否则，重量为 $x$ 的石头将会完全粉碎，而重量为 $y$ 的石头的新重量为 $y - x$。
>
> 最后，最多只会剩下一块石头。返回此时石头最小的可能重量，如果没有石头剩下，就返回 $0$。

示例：

```
输入：[1, 2, 1, 7, 9, 4]
输出：0
解释：
Round 1：(2, 4) -> 2 => [1, 1, 7, 9, 2]
Round 2：(7, 9) -> 2 => [1, 1, 2, 2]
Round 3：(2, 2) -> 0 => [1, 1]
Round 4：(1, 1) -> 0 => 0
```

### 思路

将该问题转化为算法：0-1 背包问题：

- 思考：
  - 原问题中如果一组数字接近所有数字之和的 1/2，那么两组数字（接近的和剩下的分成两组数字）之差肯定越小。
  - 比如 `[1, 2, 1, 7, 9, 4]` 这个例子，所有数字之和是 24，所以如果能找到一组数字的和是 12，那么剩下的数字的和也会是 12，最后肯定能得到最小值 0。
- 现在假设有一个背包，其容量为 $24/2 = 12$，接着我们将这些石头看做一堆重量与价值相同物品，分别为 `[1, 2, 1, 7, 9, 4]`，那么通过求解这个背包的最大价值，即可算出原问题的最优结果。
- 比如算出来的最大价值为 $x$，则原问题的答案为 $(24 - x) - x = y$
