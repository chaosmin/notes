# 算法：选择排序

## 题目

## 思路

每轮从未排序部分选最小值，与当前位置交换。

## 代码

```java
public static void selectionSort(int[] arr) {
    for (int i = 0; i < arr.length; i++) {
        int minIndex = i;
        for (int j = i + 1; j < arr.length; j++) {
            if (arr[j] < arr[minIndex]) minIndex = j; // 更新最小值索引
        }
        int temp = arr[i];
        arr[i] = arr[minIndex];
        arr[minIndex] = temp;
    }
}
```

## 复杂度分析

时间复杂度 $O(n^2)$
