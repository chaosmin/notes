# 算法：冒泡排序

## 题目

## 思路

相邻两元素两两比较，将最大/小值逐步冒泡至末尾。

## 代码

```java
public static void bubbleSort(int[] arr) {
    for (int i = 0; i < arr.length - 1; i++) {
        for (int j = 0; j < arr.length - i - 1; j++) {
            if (arr[j] > arr[j + 1]) {
                int temp = arr[j];
                arr[j] = arr[j + 1];
                arr[j + 1] = temp;
            }
        }
    }
}
```

## 复杂度分析

时间复杂度 $O(n^2)$
