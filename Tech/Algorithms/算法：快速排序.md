# 算法：快速排序

## 题目

## 思路

**原理**：分治法。选基准值 pivot，将小于基准值的放左边，大于的放右边，递归处理左右子数组。

**特点**：不稳定，平均性能最优，但是最坏情况（有序数组）退化为 $O(n^2)$

## 代码

```java
public static void quickSort(int[] arr, int low, int high) {
    if (low < high) {
        int pivot = partition(arr, low, high);
        quickSort(arr, low, pivot - 1);
        quickSort(arr, pivot + 1, high);
    }
}

private static int partition(int[] arr, int low, int high) {
    int pivot = arr[high];
    int i = low - 1;
    for (int j = low; j < high; j++) {
        if (arr[j] < pivot) {
            i++;
            swap(arr, i, j);
        }
    }
    swap(arr, i + 1, high);
    return i + 1;
}
```

## 复杂度分析

- 时间复杂度 $O(nlogn)$
- 空间复杂度 $O(logn)$
