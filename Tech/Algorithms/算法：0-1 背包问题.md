# 算法：0-1 背包问题

## 题目

> 给你一个可放总重量为 $W$ 的背包和 $N$ 个物品，对每个物品有重量 $w$ 和价值 $v$ 两个属性，那么第 `i` 个物品的重量为 $w[i]$，价值为 $v[i]$。现在让你用这个背包装物品，问最多能装的价值是多少？

示例：
```
输入：W = 5，N = 3，w = [3, 2, 1]， v = [5, 2, 3]
输出：8
解释：选择 i = 0 和 i = 2 这两件物品，总重量 4 小于 W，同时获得最大价值 8。
```

## 思路

### 动态规划求解前置条件

1. **重叠子问题**：在穷举的过程中存在重复计算的问题，各种排列组合肯定存在该情况；
2. **无后效性**：当选定一个物品后，重量与价值也随之确定了，后续选择的物品不会对这个选择产生副作用，因此无后效性；
3. **最优子结构**：当选定一个物品后，继续做决策时，可以使用之前计算的重量和价值，后续的计算可以通过前面的状态推导出来。因此该问题存在最优子结构。

### 状态转移方程

1. **初始化状态**：背包的容量 $r_w$ 为 0 或者物品的数量 $t_n$ 为 0；
2. **状态参数**：物品数量 $N$ 和背包还能装下的重量 $W$；
3. **决策**：将物品放入背包，$w[t_n], v[t_n]$

$$
DP(t_n, r_w) = 
\begin{cases}
0, t_n \le 0 \\
0, r_w \le 0 \\
DP(t_n-1, r_w), r_w < w[t_n] \\
max\{DP(t_n-1, r_w), DP(t_n-1, r_w-w[t_n])+v[t_n]\}\\
\end{cases} 
$$

## 代码

### 递归解法

```java
/*
 * tn: traversed n，即已经遍历过的物品；
 * rw: reserved w，即背包还能容量的重量。
 */
DP(int tn, int rw) {
  // 当遍历完所有物品时，就该返回 0 了，因为没有物品也就没有价值了 
  if tn < 0 return 0
  // 当背包还能容纳的重量已经小于当前物品的重量时，显然这个物品不能放入背包
  if rw < w[tn] return DP(tn - 1, rw)
  // 作出决策，该不该放入物品：
  // 1. 放入：那么价值是 DP(tn - 1, rw - w[tn])
  // 2. 不放入：那么价值是 DP(tn - 1, rw)
  return max(DP(tn - 1, rw), DP(tn - 1, rw - w[tn]) + v[tn])
}
```

### 动态规划解法

```java
int dp(int[] w, int[] v, int N, int W) {
  int[][] dp = new int[N+1][W+1];
  
  for (int i = 0; i < N + 1; i++) { dp[i][0] = 0; } 
  for (int j = 0; j < W + 1; j++) { dp[0][j] = 0; } 
  
  for (int tn = 1; tn < N + 1; tn++) {
    for (int rw = 1; rw < W + 1; rw++) { 
      if (rw < w[tn]) { 
        dp[tn][rw] = dp[tn-1][rw];
      } else { 
        dp[tn][rw] = Math.max(dp[tn-1][rw], dp[tn-1][rw-w[tn]] + v[tn]);
      }
    }
  }
  return dp[N][W];
}
```
