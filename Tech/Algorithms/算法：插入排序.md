# 算法：插入排序

## 题目

## 思路

将未排序元素插入已排序部分的正确位置。

对部分有序的数据效率高，接近 $O(n)$

## 代码

```java
public static void insertionSort(int[] arr) {
    for (int i = 1; i < arr.length; i++) {
        int tmp = arr[i], j = i - 1;
        while (j >= 0 && arr[j] > tmp) { // 后移大于key的元素
            arr[j + 1] = arr[j];
            j--;
        }
        arr[j + 1] = tmp; // 插入key
    }
}
```

## 复杂度分析

时间复杂度 $O(n^2)$
