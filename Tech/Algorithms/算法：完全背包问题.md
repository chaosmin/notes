# 算法：完全背包问题

#动态规划

### 题目

> 给你一个可放总重量为 $W$ 的背包和 $N$ 个物品，对每个物品有重量 $w$ 和价值 $v$ 两个属性，那么第 $i$ 个物品的重量为 $w[i]$，价值为 $v[i]$。现在让你用这个背包装物品，每种物品都可以选择任意多个，问这个背包最多能装的价值是多少？

示例：

```
输入：W = 5，N = 3，w = [3, 2, 1]，v = [5, 2, 3]
输出：15
解释：选 i = 2 的物品5次，总价值为 5 * 3 = 15。
```

### 思路

与算法：0-1 背包问题的区别：

- 0-1 背包问题：针对当前物品，是放入背包，还是不放入背包时的价值最大；
- 完全背包问题：针对当前物品，应放入多少件时的价值最大。

动态规划求解前置条件：

- **重叠子问题**：穷举的过程中肯定存在重复计算的问题；
- **无后效性**：选择了一个物品后，背包还能容纳的重量和总价值是确定的，后续选择的物品（即是相同）也不会对当前这个选择产生副作用；
- **最优子结构**：选定了一个物品后，继续做决策时，可以使用之前计算的重量和价值。

构建状态转移方程：

- **初始化状态**：物品种类 $t_n = 0$ 或其价值 $r_w = 0$；及背包还能容纳的重量不足时
- **状态参数**：背包内物品的数量 $N$ 在增加，同时背包还能装下的重量 $W$ 在减少。
- **决策**：由于每种物品的数量是无限制的，对于第 $t_n$ 种物品，我们有k种选择（其中 $0 \le k * w[t_n] \le W$）：可一直拿到第 $(W/w[t_n])$ 件物品为止。

$$
DP(t_n, r_w) = 
\begin{cases}
0, t_n \le 0 \\
0, r_w \le 0 \\
DP(t_n - 1, r_w), r_w < w[t_n] \\
max\{DP(t_n - 1, r_w - k * w[t_n]) + k *v[t_n]\},(0 \le k \le (r_w/w[t_n]) \\
\end{cases}
$$

### 代码

```java
int bag(int[] w, int[] v, int N, int W) {
  int[][] dp = new int[N+1][W+1];
  
  for (int i = 0; i < N + 1; i++) { dp[i][0] = 0; }
  for (int j = 0; j < W + 1; j++) { dp[0][j] = 0; }
  
  for (int tn = 1; tn < N + 1; tn++) {
    for (int rw = 1; rw < W + 1; rw++) {
      dp[tn][rw] = dp[tn-1][rw];
      for (int k = 0; k < rw / w[tn]; k++) {
        dp[tn][rw] = Math.max(dp[tn][rw], dp[tn-1][rw-k*w[tn]] + k * v[tn]);
      }
    }
  }
  return dp[N][W];
}
```

### 复杂度分析

三重循环：

- 遍历物品
- 遍历剩余容量
- 遍历物品数量

假设物品数量为 $k$，背包容量为 $v$，则时间复杂度为 $O(kv^2)$，出现指数级别的复杂度不是一件好事。需要探讨为何时间复杂度会增加？

根据状态转移方程，加入要拿第 $t_n$ 个物品时，当前物品的重量为 $w[t_n]$，需要考察放入 0 ... k 件物品时的价值并取最大值。

因此要求剩余容量为 $rw$ 即 $(rw - 0 * w[t_n])$ 时的最优解，需要遍历求出 $rw - 0 * w[t_n]$ ... $rw - k * w[t_n]$，然后在其中挑出最大的那个作为子问题的解，从而导致了解法多了一层循环。
