# 算法：三数之和

#排序 #双指针

## 题目

> 给你一个整数数组 `nums` ，判断是否存在三元组 `[nums[i], nums[j], nums[k]]` 满足 `i != j`、`i != k` 且 `j != k` ，同时还满足 `nums[i] + nums[j] + nums[k] == 0` 。请你返回所有和为 `0` 且不重复的三元组。

**注意：** 答案中不可以包含重复的三元组。

**示例 1：**
```
输入：nums = [-1,0,1,2,-1,-4]
输出：[[-1,-1,2],[-1,0,1]]
```

**示例 2：**
```
输入：nums = [0,1,1]
输出：[]
```

**示例 3：**
```
输入：nums = [0,0,0]
输出：[[0,0,0]]
```

**提示：**
`3 <= nums.length <= 3000`
`-105 <= nums[i] <= 105`

## 思路

这道题跟[[算法：两数之和]]相比多了一个数字，那么我们只需要先确定一个数，之后利用双指针确定剩下两个 `nums[j] + nums[k] = -nums[i]` 的数就好了。

可以做几个优化：

1. 如果发现 `nums[i] == nums[i - 1]`，那么 `nums[i]` 与后面两数组成和为 0 的三元组也能由 `nums[i - 1]` 组成，这就重复了，可以直接 continue 外层循环。
2. 如果 `nums[i]` 与后面最小的两个数相加 >0，那么后面不可能存在三数之和等于 0 的情况了，直接 break 外层循环；
3. 如果 `nums[i]` 与后面最大的两个数相加 <0，那么内层循环不可能存在三数之和等于 0，但继续枚举 `nums[i]` 可以变大，所以后面还有机会，continue 外层循环。

## 代码

```java
class Solution {
    public List<List<Integer>> threeSum(int[] nums) {
        Arrays.sort(nums);
        List<List<Integer>> ans = new ArrayList<>();
        int n = nums.length;
        for (int i = 0; i < n - 2; i++) {
            int x = nums[i];
            if (i > 0 && x == nums[i - 1]) continue; // 跳过重复数字
            if (x + nums[i + 1] + nums[i + 2] > 0) break; // 优化一
            if (x + nums[n - 2] + nums[n - 1] < 0) continue; // 优化二
            int j = i + 1;
            int k = n - 1;
            while (j < k) {
                int s = x + nums[j] + nums[k];
                if (s > 0) {
                    k--;
                } else if (s < 0) {
                    j++;
                } else { // 三数之和为 0
                    if (j == i + 1 || nums[j] != nums[j - 1]) {
                        ans.add(List.of(x, nums[j], nums[k]));
                    }
                    j++;
                    k--;
                }
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：$O(n^2)$，其中 n 为 `nums` 的长度。排序 $O(nlogn)$。
- 空间复杂度：$O(1)$。返回值不计入。忽略排序的栈开销。
