# 主线第十六章配队指南

> **最后更新**: 2026年7月 | 第十六章于2026年1月解锁，当前最难主线关卡 | **注意：16章无周回，通关后不锁油**

---

## 一、核心机制

| 机制 | 16-1 / 16-2 | 16-3 / 16-4 |
|------|-------------|-------------|
| **支援舰队类型** | 潜艇支援 | 航母支援 |
| **敌人特点** | 有航母敌人，主力放照明弹 | 无航母，有战争迷雾和机场 |
| **主要威胁** | 前排生存压力 | 跨射 + 泥头车 + 自爆飞机，后排压力大 |
| **BOSS出现** | 正常 | 仅需5战即出 |
| **周回** | 无（通关后不锁油） | 无（通关后不锁油） |

> **输出提示**：16章整体生存压力低于预期，**BOSS输出是主要瓶颈**（易超时），优先保证后排输出而非过度堆肉。

## 六、关键战术提醒

1. **阵型**：道中推荐复纵阵，BOSS队复纵或轮型阵
2. **接敌禁忌**：主力队不要打侦查敌人。大型主力（人形战列）极度危险
3. **潜艇时机**：
   - 侦查敌人约 2:48 召唤
   - 大主约 2:35 召唤
   - BOSS约 1:55 召唤
   - **不要早于2:40召唤，否则容易沉**
4. **16-4大型战列群**：人形战列敌人可一炮击沉[[独角兽改]]，前3战不用潜艇，第4战必须用潜艇支援
5. **16-4 BOSS路线**：最快4战后出BOSS，武藏队保留1颗弹药打BOSS
6. **迷雾**：BOSS战前将道中队移到地图中间，驱散更多迷雾降低敌人机动加成
7. **制空权**：务必保持**制空权优势或确保**，否则敌人会有额外空中支援
