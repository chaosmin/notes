# 主线第十五章配队指南

> **最后更新**: 2026年1月 | 参考: 井号、臧贺、朝武白等攻略作者

---

## 一、核心机制

| 机制 | 说明 |
|------|------|
| **支援舰队** | 提供战斗机拦截支援，只看等级与装备练度。优先选多战斗机航母 |
| **特殊航母（超航）** | 地图存在「超航」敌人，必须优先击破，否则全程受敌方航母支援。15-4有 **两个** 超航 |
| **BOSS撤退机制** | 15-3需打2次BOSS，15-4需打3次BOSS。**同一舰队连续打相邻两次BOSS会触发-30%伤害/+30%受伤debuff** |
| **烟幕机制** | 约20秒出第一次烟幕，之后每30秒一次，持续约20秒，影响我方瞄准 |
| **阵型** | 道中全程**复纵**，BOSS队全程**轮形** |

### 15-3 BOSS轮换
- 道中队 → 第一次
- BOSS队 → 第二次

### 15-4 BOSS轮换
- **BOSS队** → 第一次
- **道中队** → 第二次
- **BOSS队** → 第三次

## 六、通关流程

### 15-1 & 15-2
- 无需反潜装，压力较小
- 15-2：BOSS队见BOSS直接召潜艇，可用「攒空袭消弹」技巧防跨射

### 15-3
1. 战术驱离左上三星大侦
2. 道中队打超航 → 打2战道中 → 打BOSS1
3. 道中队再打2战道中（选弱敌）
4. BOSS队打BOSS2

### 15-4
1. 战术驱离右下三星大侦
2. 道中队打**两个**超航（左上+右下各一个）
3. 道中队打1战道中
4. **BOSS队**打BOSS1（第一次）
5. 道中队捡弹药 → 打2战道中 → 打BOSS2（第二次）
6. 道中队再打1战道中（弱敌）
7. **BOSS队**打BOSS3（第三次，留1颗弹药+1次潜艇）

> **弹药管理**：弹药≤3/5时捡，最后一个弹药留给BOSS3再捡。
