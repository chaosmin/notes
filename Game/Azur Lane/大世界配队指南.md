# 大世界配队指南（Operation Siren）

> **最后更新**: 2026年3月 | 参考: 小圣第17期、猛蓝、深红的天使等攻略作者

---

## 一、大世界概述

大世界（Operation Siren / 余烬）是碧蓝航线的终局模式，可派遣 **4支水面舰队 + 1支潜艇舰队**（共27艘船）。

| 特性 | 说明 |
|------|------|
| **无自动回复** | 离开海域不会自动回血，需使用紧急维修道具或回港修整 |
| **侵蚀等级** | 1~6级，敌人等级从62到118+ |
| **无石油消耗** | 大世界不消耗石油，不消耗心情，适合练级 |
| **核心产出** | 装备研发材料、META舰船结晶、指挥喵经验 |
| **治疗反转** | 部分BOSS带有治疗反转模块，奶妈技能会变成伤害 |

---

## 二、核心配队思路

当前版本强度溢出，采用 **1道中队 + 1补刀/攻坚队 + 2跨队啦啦队** 的四队体系。

---

## 三、万能道中队（核心主力）

目标：一队完成大世界高效全清。本队为绝对核心。

### 后排（2026年3月最新版）

| 位置 | 推荐舰船 | 说明 |
|------|----------|------|
| 旗舰 | [[独角兽改]]（平衡型） / [[英仙座]]（极限短猫型） | 奶航，保证续航 |
| 上僚 | [[狮]] | 超预装填弹幕，道中绝对核心 |
| 下僚 | [[天鹰]] / [[千濑]] / [[μ可畏]] | 预装填正航，[[天鹰]]最通用 |

> [[狮]]是非顶配时（缺+13装备、戒指）可能不如[[天鹰]]稳，建议根据练度选择。

### 前排（最新三重巡体系，2026/03）

| 位置 | 推荐舰船 | 说明 |
|------|----------|------|
| 承伤位 | [[金狮]] | 橘子弹幕清杂优异，承伤+输出 |
| 输出位 | [[莫斯科]] | 全穿盾主副炮，138驱逐炮100%效率 |
| 输出位 | [[威廉·D·波特]] | 5秒鱼雷错峰补刀，旗舰增伤辅助 |

### 替代方案

| 原舰船 | 可替换 |
|--------|--------|
| [[莫斯科]] | [[特拉法尔加]]（穿透光刀清杂、皇家拐）、[[哈尔滨]]（专克侦查敌人） |
| 前排整体 | 三光刀（[[爱宕]] + [[特拉法尔加]] + [[伊吹]]）或六雷（[[哈尔滨]] + [[渡良濑]] + [[伊吹]]） |

> **伊吹**是开幕斩击皇帝，短猫效率提升甚至超越[[狮]]，短猫必带。

### 短猫实测数据
- 三重巡打大航几乎稳6秒
- 侵蚀5平均 7.47秒/战，较之前[[威廉·D·波特]]配置提升0.82秒

## 六、跨队啦啦队（2队）

剩余两队全部用于提供跨队支援，按跨队推荐榜依次放置：

| 优先级 | 舰船 |
|--------|------|
| T0 | [[莫斯科]]、[[科洛蒂娅]]、[[苏盟]]、[[俾斯麦Zwei]] |
| T1 | [[列克星敦II]]、[[关岛]]、[[约克城II]] |
| T2 | [[前卫]]、[[独立改]]、[[华甲改]] |

这些船不需要额外培养指挥猫和装备，放在舰队里即可提供跨队buff。

## 八、萌新过渡建议

| 阶段 | 操作 |
|------|------|
| 初期 | 优先练好1支道中队（[[独角兽改]] + [[天鹰]]/[[英仙座]] + 强力战列）+ 1支输出队 |
| 道中 | [[独角兽改]]必备，搭配[[英仙座]]或[[天鹰]] |
| 前排 | 雷暴队通用（[[伊吹]] + [[云仙]] + [[渡良濑]]），资源要求低 |
| 进阶 | 优先培养[[狮]]、[[特拉法尔加]]、[[莫斯科]]等新世代强力角色 |
