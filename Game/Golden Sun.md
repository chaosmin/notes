# 黄金太阳系列 (Golden Sun)

由 **Camelot**（高桥兄弟）开发、任天堂发行的奇幻 RPG 系列。GBA 时代画面与系统顶级之作，被广泛誉为"最好的掌机 RPG 之一"。魔法兼用于战斗与地图解谜的**精神力 (Psynergy) 系统**、可收集元素精灵改变职业的**精灵 (Djinn) 系统**为其核心特色。

原计划登陆 N64，因平台末期转向 GBA 开发。因卡带容量限制，原本一部作品拆分成了前两作。音乐由传说系列御用作曲家**樱庭统**操刀。

## 世界观：维亚德 (Weyard)

远古时代，**炼金术** 驱动了空前繁荣的文明。然而战乱随之而起，炼金术最终被封印——**四颗元素之星**藏于阿鲁法山 (Mt. Aleph) 神殿中，只有同时点燃**四座元素灯塔**才能完全释放炼金术。

- **四元素：** 地 (Venus)、火 (Mars)、风 (Jupiter)、水 (Mercury)
- **元素使 (Adept)：** 能操控元素精神力之人
- **四座灯塔：** 水星灯塔、金星灯塔、木星灯塔、火星灯塔
- **精灵 (Djinn)：** 遍布世界的元素精灵，与元素使结盟后可改变其职业与能力
- **精神力 (Psynergy)：** 元素使的法术，既用于战斗，也用于地图探索与解谜

炼金术的封印并非保护，而是枷锁——没有炼金术的能量循环，维亚德世界正在缓慢走向消亡。

## 剧情概要

### 《开启的封印》(2001)

> 17 岁的地元素使 **罗宾**（Isaac）与火元素使 **杰利德**（Garet）在阿鲁法山探险时，火之一族的 **萨帝诺斯**（Saturos）与 **梅娜迪**（Menardi）闯入神殿夺走三颗元素之星，并绑架了罗宾的同伴。罗宾踏上追击之旅，沿途中风元素使 **伊万**（Ivan）与水元素使 **米雅莉**（Mia）加入。虽然罗宾在金星灯塔杀掉了萨帝诺斯与梅娜迪，却未能阻止灯塔点燃——而萨帝诺斯的同伙 **加西亚**（Felix）继续前往剩余两座灯塔。

### 《失落的时代》(2002)

> 视角翻转——玩家操控前作的"反派"**加西亚**（18 岁地元素使）与妹妹 **加丝敏**（Jenna）、谜之风使 **西芭**（Sheba）、古代雷姆利亚水使 **皮卡德**（Piers）。他们继续点燃剩余两座灯塔，因为若不释放炼金术，世界将因能量枯竭而消亡。幕后操纵者是火之一族的 **加斯特**（Karst）与 **亚卡迪奥**（Agatio）这对兄妹——他们实为水星灯塔的 **亚历斯亚**（Alex）的棋子。最终罗宾与加西亚两队在火星灯塔汇合，击败亚历斯亚召唤的三头龙（实为被变为龙的罗宾之父等人），点燃最后一座灯塔。**炼金术回归维亚德**——世界获救，但新时代也带来了新的威胁。

### 《漆黑的黎明》(2010)

> 《失落的时代》**30 年后**。炼金术的回归使大陆漂移，新的国家与物种诞生。然而能吸取精神力的 **精神力黑洞**（Psynergy Vortex）在世界各地出现。主角 **穆特**（Matthew，罗宾与加丝敏之子）与 **泰瑞**（Tyrell，杰利德之子）、**卡莉丝**（Karis，伊万之女）、**克劳温**（Rief，米雅莉之子）等新一代元素使踏上调查之旅。途中陆续加入水之王子 **哈鲁玛尼**（Amiti）、兽人公主 **斯泰拉**（Sveta）、海盗 **雷欧雷欧**（Eoleo）、巫女 **卑弥**（Himi）。
>
> 一行人被军事强国兹亚帕兰的间谍 **黑桃/红心** 利用，启动了露娜灯塔，引发"被诅咒的日蚀"。幕后黑手 **艾斯**（实为 30 年前失踪的亚历斯亚）意图借此吸收神鸟之光获得无尽生命。最终穆特一行启动 **阿波罗光之增幅机**终结日蚀，但迎接他们的却是一个前所未有的巨大精神力黑洞——系列第三作在悬念中结束。

## 精灵与职业系统 ★ 核心特色

### 精灵收集

四大元素共 **72 只精灵**（一代 28 + 二代追加 44；三代另有新精灵）。散布于世界各地的迷宫、原野与隐藏地点。每只精灵有独特外形与性格，需要以特定方式接触或战斗后才能收服。

### 附身 (Set) vs 待命 (Standby)

每只精灵有两种状态：

| 状态 | 效果 |
|------|------|
| **附身 (Set)** | 装备在角色身上，提供属性加成，改变角色**职业**，解锁对应精神力 |
| **待命 (Standby)** | 解除附身后进入待命。不再提供职业/属性加成，但可用于**召唤** |

战斗中可从 Set 切换为 Standby（使用精灵技能后自动切换），召唤后精灵进入冷却（数回合后自动恢复 Set 状态）。

### 职业系统

角色**没有固定职业**——职业完全由附身的精灵种类与数量决定。

- **单元素职业：** 只装备与自身同元素的精灵。基础稳妥，能力均衡。
- **双元素职业：** 混搭两种元素。跨度越大、职业越强。地+火 = Brute/Samurai 等高攻击系；风+水 = Sage 高等法师系。
- **三元素职业：** 装备来自两种外元素的精灵（共 6-7 只）。最顶级职业——Ninja（高速 + AoE）、Samurai（最强单体）、White Mage（最强回复）。

### 一线职业速查

| 角色 | 默认元素 | 推荐顶级职业 |
|------|----------|-------------|
| 罗宾 / 加西亚 | 地 | Samurai（Quick Strike）、Ninja（AoE）、Berserker（最高 ATK） |
| 杰利德 / 加丝敏 | 火 | Dragoon（坦克+回复）、Samurai、Berserker |
| 伊万 / 西芭 | 风 | Sage（最高 PP + 速度，法师巅峰）、White Mage（最强奶） |
| 米雅莉 / 皮卡德 | 水 | Sage、White Mage、Ranger（魔法输出） |

### 召唤系统

消耗待命精灵发动强力全体攻击。需要 1-4 只同元素精灵可召唤对应等级神兽。续作增加**联合召唤**（需两种元素的精灵同时待命）。召唤后精灵进入冷却（不可附身 / 不可再召唤），职业可能因此临时降级——这是黄金太阳战斗策略的核心张力：**要爆发召唤还是维持职业？**

## 精神力与地图解谜

不同于大多数 RPG，"魔法"不仅用于战斗，更是**遍历地图与解谜的核心工具**。几乎所有迷宫都要求玩家在战斗外用精神力移动障碍、架桥、冻结水面、照明、读心 NPC、透视隐藏通道等。

| 精神力 | 元素 | 地图用途示例 |
|--------|------|-------------|
| 移动 (Move) | 地 | 推动巨石、机关 |
| 生长 (Growth) | 地 | 让藤蔓生长为可攀爬的梯子 |
| 冰冻 (Frost) | 水 | 将水面冻结为可通行的冰面 |
| 旋风 (Whirlwind) | 风 | 卷走拦路藤蔓、吹动漂浮平台 |
| 透视 (Reveal) | 风 | 发现隐藏入口、机关与宝箱 |
| 读心 (Mind Read) | 风 | 读取 NPC 内心想法（解谜线索） |
| 爆炸 (Force) | 火 | 炸开巨石、打开通道 |

## 战斗系统

- **回合制 RPG**，伪 3D 旋转视角（GS1/GS2），全 3D（GS3）
- **武器攻击、精神力、精灵技能、召唤** 为四种主要行动
- 召唤演出效果在 GBA 时代震撼业界，是系列标志性视觉奇观
- 前两作包含**联机对战模式**（竞技场），第三作取消
