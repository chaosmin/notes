# JOJO的奇妙冒险 彪马野郎 (JoJo's Bizarre Adventure (2012))

《JOJO的奇妙冒险》改编自**荒木飞吕彦**（荒木飛呂彦）的长篇漫画。2012 年由 **david production** 动画化第一部《幻影血脉》与第二部《战斗潮流》，此后依次动画化《星尘斗士》《不灭钻石》《黄金之风》《石之海》。2026 年，系列第七部《彪马野郎》（スティール・ボール・ラン / Steel Ball Run，又译《飙马野郎》）动画化，于 Netflix 独家上线。

《彪马野郎》舞台设定在 1890 年的美国，一场横跨大陆的骑马竞速「**Steel Ball Run**」大奖赛拉开帷幕，奖金高达 5000 万美元。因故下半身瘫痪的前骑师**乔尼·乔斯达**（Johnny Joestar）邂逅使用「回转」（Spin）之术的异国骑手**杰洛·齐贝林**（Gyro Zeppeli），在回转之力短暂恢复他腿部活动后，乔尼决心投身大赛，追寻力量的真相。

## 世界观设定

- **1890 年美国：** 故事舞台，从圣地亚哥到纽约的跨大陆赛马路线。
- **Steel Ball Run 大赛：** 横跨大陆的骑马竞速，奖金 5000 万美元。
- **回转（Spin）：** 杰洛一族传承的旋转之力，投出的钢球蕴含神秘能量。
- **替身（Stand）：** 本作描绘「替身」概念的诞生过程。
- **圣者遗体（Holy Corpse）：** 隐藏在大赛路线中的关键，各方势力争夺之物。

## 剧情概要

### 系列前六部（2012–2022）

从初代乔纳森·乔斯达与吸血鬼迪奥的宿命对决（第一部），到二乔乔瑟夫·乔斯达的智斗（第二部）、空条承太郎的替身冒险（第三部）、东方仗助的小镇日常（第四部）、乔鲁诺·乔巴拿的黑帮之旅（第五部），再到空条徐伦的越狱与宿命（第六部），「乔斯达家族」与「迪奥」的因缘贯穿始终。

### 第七部「彪马野郎」（2026）

舞台转向 1890 年的美国。瘫痪的乔尼与杰洛结伴参加 Steel Ball Run 大赛，途中穿越「恶魔掌心」等险境，并逐渐卷入围绕「圣者遗体」的巨大阴谋，与总统**法尼·瓦伦泰**等人展开对峙。

## 原作

漫画第七部《Steel Ball Run》于 2004–2011 年连载（初期标题不含「JoJo」，后正式纳入系列），是荒木飞吕彦自 1987 年连载至今的作品中最受好评的篇章之一。动画由 david production 制作。
