# DARK MACHINE THE ANIMATION (DARK MACHINE THE ANIMATION)

原创机甲 × 电子竞技电视动画。近未来日本，海平面急剧上升使千叶与关东本土分离，一款名为 **「Dark Machine」** 的电竞机甲对战游戏风靡全球，甚至改变了日本的经济结构。日本唯一的「Dark Machine」经济特区 **Golden Valley（ゴールデンバレー）** 由继承最强玩家称号 **「千鬼」** 的第七代——**アジマ（Ajima）** 统治着顶点。

主角 **カイリ（Kairi）** 怀揣已故祖父留下的遗言「去找千鬼」来到 Golden Valley，偶然救下被アジマ手下追赶的少女 **ルドラ（Rudra）**，就此被卷入并成为 Dark Machine 玩家。在激烈的对战中，カイリ逐渐展露才能，一步步走向与「千鬼」对决的命运。

本作是同名游戏《Dark Machine》（PC / iOS / Android）与动画同步推进的跨媒体企划，原作为 **Project Carbuncle**，谷口悟朗担任创意制作人，天神英贵担任游戏与动画共通的机甲设计。动画由 **Production +h.**（《地球外少年少女》《恶魔恶魔恶恶魔》）制作，富士电视台牵头制作委员会。2024 年圣地亚哥动漫展上首次公布。

## 世界观设定

- **近未来日本：** 海平面急速上升，千叶被从关东切割出去。
- **Dark Machine：** 驾驶巨大机体（マシン）对战的电竞游戏，全球人气压倒性，已深度嵌入日本经济。
- **Golden Valley：** 日本唯一的 Dark Machine 经济特区，故事主舞台。
- **千鬼（Senki）：** 授予最强玩家的称号，现任为第七代アジマ。
- **主角机：** 在活动 PV 中首次公开，机体为白色。
